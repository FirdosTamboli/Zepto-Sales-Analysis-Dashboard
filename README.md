# 🛒 Zepto Sales Analysis Dashboard

## 📊 Power BI Business Intelligence Project

An interactive **Zepto Sales Analysis Dashboard** built using **Microsoft Power BI** to analyze sales performance, outlet characteristics, product categories, customer ratings, and establishment trends.

## 📌 Project Overview

The **Zepto Sales Analysis Dashboard** provides a comprehensive view of grocery sales performance across different outlets and product categories.

The dashboard allows users to analyze key business metrics such as:

- Total Sales
- Average Sales
- Number of Items
- Average Customer Rating
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Item Type
- Sales by Protein Content
- Sales by Outlet Establishment Year

Interactive filters allow users to explore the data based on **Outlet Location Type, Outlet Size, and Item Type**.

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall Zepto sales performance.
- Identify high-performing outlet types and sizes.
- Analyze sales across different product categories.
- Understand the contribution of different outlet tiers.
- Analyze sales based on protein content.
- Study sales trends based on outlet establishment year.
- Monitor customer ratings.
- Build an interactive and user-friendly business dashboard.

## 🧹 Data Preparation

The following data preparation steps were performed:

1. Imported the sales dataset into Power BI.
2. Checked the dataset for missing and inconsistent values.
3. Cleaned and transformed the data using Power Query.
4. Standardized categorical fields.
5. Created required calculated columns and measures.
6. Developed DAX measures for KPIs.
7. Built interactive charts and visualizations.
8. Added slicers for interactive filtering.
9. Designed the final dashboard layout.
